# human_typer

Программа, которая открывает текстовый редактор и печатает текст
посимвольно, как будто это делает человек.

## Возможности

- Русский интерфейс
- Поддержка Unicode (русские буквы) через wtype
- Выбор редактора: vim, nvim, nano, emacs, kate
- Выбор скорости: медленно, средне, быстро
- Текст из файла или вручную
- Сохранение и выход автоматически

## Требования

- wtype (для Wayland)
- kitty (для vim/nvim/nano/emacs)
- Один из редакторов: vim, nvim, nano, emacs, kate

## Сборка

cargo build --release

## Запуск

./target/release/human_typer
